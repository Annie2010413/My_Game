## 一、遊戲目標
小帕是一名台大資管的大一新生，他對於大學充滿憧憬、迫不及待地要體驗大學的種種，俗話說大學有三學分：愛情、社團和課業，所以我們設定小帕的友情值（Friendship）愛情值（Romance）學識值（Knowledge）都必須達到一定的值才能畢業。而大學四年一路上會遇到哪些挑戰和故事呢？他大概沒想到自己會在管圖遇見一群好 homie、沒想到每週都有 debug 不完的程設作業和寫不出來的 Webwork、沒想到會交到一個可愛的女朋友、沒想到會去當家教、沒想到會參加管舞喝酒局⋯⋯實在是太有趣了！快來玩玩看我們的遊戲，和小帕一起體驗豐富又繽紛到大學生活吧！

## 二、道具與敵人
### （一）道具（Item）  
- Good person card （好人卡） : 
    - 簡介：可以召喚出幫玩家擋酒的好人，玩家還能跟好人成為朋友
    - 使用效果：當局猜拳輸了之後可免除選酒懲罰一次，同時Friendship 上升

- Hammer （星爆氣流錘） : 
    - 簡介：在管圖角落發現的神祕槌子
    - 使用效果：計算敲擊空白鍵的次數變兩倍

- Girlfriend‘s Help （女友的幫助） :
    - 簡介：體貼的女友願意幫忙寫作業
    - 效果：在 Webwork 遊戲中會自動完成一半的答案

- Salary （薪水 660） : 
    - 簡介：家教關打贏學生會得到 660 元的薪水可以用來買 AI
    - 使用效果：在 debug 關會幫助回答問題
	
### （二）敵人（Enemy）
- Deadline（死線）：當死線等級過高，在 Debug 遊戲中每題可用時間將會減少 20 秒 （遊戲中有兩題，總時間由 1 分鐘變成 40 秒）。

- Liver（玩家的肝指數）：過度操勞的肝臟會抗議，拼酒遊戲會被強制結束，那關即失敗。

- Emo（玩家的難過程度）：當玩家太 Emo（Emo 等級 >= 1），CardMatch 遊戲中的圖片亮度會變低。

- Student（家教笨學生）：在玩家趕 Webwork 死線的時候突然問玩家問題，遊戲時間凍結 5 秒
